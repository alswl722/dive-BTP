# 외부 데이터 연동 설계노트

> 심사 담당자가 신청기업의 **실체·건전성·기술력**을 서류 밖에서 검증하도록, 무료 공공데이터를 스코어카드에 붙이기 위한 설계·근거 노트.
> 대상 페르소나: 부산TP 심사 담당자/관리자. (기업 대상 기능 아님)
> 관련: [기술축_설계노트.md](기술축_설계노트.md)(§8-2 외부 데이터) · [특허데이터정리.md](특허데이터정리.md)(KIPRIS 원장 조인 한계)

## 0. 전제와 범위

- **전제**: 실 운영 단계로 신청기업의 **사업자등록번호(식별 데이터)** 를 보유한다고 가정. (현재 샘플은 `기업일련번호` 비식별 → 아래 소스는 대부분 사업자번호 키라, 샘플 데이터에는 **목업/설계로만** 시연 가능. 실연동은 실 데이터 확보 후.)
- **범위**: **무료** 소스만. 유료(NICE평가정보 BizAPI, 한국기업데이터 KED, KIPA SMART5 특허등급, TCB 기술신용등급)는 §5 로드맵으로 분리.
- **원칙(CLAUDE.md 정합)**: ① 규칙기반 우선 — 외부 데이터는 대부분 명단 대조/집계라 모델 불필요. ② ETL은 config 기반(응답 필드명을 하드코딩하지 않고 매핑 분리). ③ 권한은 필터로 — 외부 데이터도 role 무관 단일 뷰에 배지/신호로 노출.

## 2. Tier 1 — 반드시 (검증 기본기)

### 2.1 국세청 사업자등록 상태조회 / 진위확인
- **주는 것**: 사업자번호로 운영상태(계속/휴업/폐업), 과세유형, 상호·대표자·개업일 진위.
- **심사 효용**: 폐업·휴업 기업 즉시 결격, 서류 진위 1차 검증. 전체 신청기업 배치 일괄 검증.
- **획득**: 무료 REST API(JSON), 1일 100만건. 국세청 원장과 ~30분 동기화. 난이도 최저.
- **출처**: https://www.data.go.kr/data/15081808/openapi.do
- **스코어카드 반영(안)**: 개요 상단 `기업상태` 배지(폐업=적색 결격), 데이터 품질 경고와 연계.

### 2.2 조달청 나라장터 부정당제재 내역
- **주는 것**: 입찰참가자격 제한(부정당업자) 명단 — 업체명·**사업자/법인번호**·제재근거법·제재기간·시작/종료일·처분상태(18개 필드).
- **심사 효용**: 공공계약 결격 = 신뢰성 결격 신호. 제재기간 중 여부 판정.
- **획득**: 무료 **파일데이터(CSV, 수시 갱신)** — 표준 REST API 아님 → 정기 다운로드·적재 필요.
- **출처**: https://www.data.go.kr/data/15137996/fileData.do
- **반영(안)**: 개요/기술 상단 `부정당제재` 경고 배지 + hover에 제재기간·근거.

### 2.3 국민연금 가입 사업장
- **주는 것**: 사업장별 가입자수·당월 고지금액. (범위: 3인↑ 법인, 10인↑ 개인)
- **심사 효용**: **실제 상시근로자·고용규모** 검증 → 서류상 인원 과장 탐지. KODATA 고용지표 교차검증.
- **획득**: 무료 API(JSON/XML)+파일.
- **주의**: 사업장명 기반 매칭이라 **동명·다사업장 오매칭** 방어 필요(사업자번호 병행).
- **출처**: https://www.data.go.kr/data/3046071/openapi.do

### 2.4 벤처확인 "유형" (중기부)
- **주는 것**: 벤처확인 유형 — **연구개발형**(연구소+R&D비), **혁신성장형**(기술 혁신성 평가), **벤처투자형**(투자유치), 예비벤처형. 전국 명단(약 3.97만개) + 유효시작/종료·확인기관.
- **심사 효용**: boolean "벤처"를 **기술형(연구개발·혁신성장) vs 투자형**으로 분해 → 기술력 심사 가중 근거.
- **획득**: **data.go.kr 파일(CSV) + 오픈API(XML/JSON)**, 연 1회 갱신. 개별 공시 조회도 가능.
- **주의**: 유효기간(보통 3년) 만료분 필터. 점수·등급은 비공개(유형까지만).
- **출처**: https://www.data.go.kr/data/15084581/fileData.do · 공시 https://www.smes.go.kr/venturein/pbntc/searchVntrCmp

## 3. Tier 2 — 고효용 (약간의 파이프라인)

### 3.1 조달청 나라장터 낙찰·계약 API
- **주는 것**: 낙찰·계약 이력 = 관급 납품 실적. **매출·거래처를 실적으로 뒷받침**. 반복 낙찰 = 조달시장 검증.
- **획득**: 무료 API. 기업 식별은 사업자번호 조인. 민수 매출은 미포함(공공조달 한정).
- **출처**: https://www.data.go.kr/data/15058815/openapi.do

### 3.2 KIPRIS 특허 심화 (특허청, 기술력 축 핵심)
"특허 건수"를 넘어 質·활동성·리스크로. 무료 Open API지만 **월 1,000회/서비스 한도** → 1,200개 배치는 **BULK 정기적재** 권장.

| 신호 | 얻는 것 | 심사 효용 | 난이도 |
|---|---|---|---|
| IPC/CPC 분류 | 기술분야 분포·집중도 | 전문형 vs 분산형, 사업-기술 정합 | 🟢 서지 기본필드 |
| 심판 이력 | 무효·권리범위확인 | IP 분쟁 리스크(확정결과와 세트) | 🟢 심판사항 API |
| 존속상태 상세 | 소멸 원인(연차료 미납 vs 만료) | 핵심자산 유지 의지 | 🟡 행정처리이력 |
| 공동출원인 | 대학·연구소 공동출원 | 산학연 협력 네트워크 | 🟡 출원인 유형분류 |
| 패밀리·PCT | 해외출원·국제출원 | 글로벌 IP 역량 | 🟡 패밀리 API |
| 상표·디자인 | 브랜드·제품 IP | 사업화 단계 완성도 | 🟢 상표/디자인 API |
| 피인용수 | forward citation | 기술 영향력·원천성 | 🟡 인용 BULK 역색인 |

- **주의**: 피인용·심사기간은 **출원연도·분야 코호트 백분위**로 보정(연식 편향). 심판·소멸은 존재 자체가 부정 아님 → 결과와 세트로.
- **출처**: 서비스 목록 https://plus.kipris.or.kr/portal/data/service/List.do · 심판사항 https://www.data.go.kr/data/15065474/openapi.do

### 3.3 NTIS 정부 R&D 심화 (기술력 축 핵심)
- **얻는 것**: ① 정부지원 대비 성과(논문·특허 산출) ② 연구비 추세·과제 대형화 ③ 부처·전문기관 편중/다양성 ④ 국가전략기술 정합.
- **획득**: NTIS OpenAPI(과제검색·성과검색·수행기관 R&D현황) + 공공데이터포털. 무료(활용신청·승인).
- **한계(로드맵)**: **기술이전·기술료·사업화 매출**과 **최종평가 등급·성실실패**는 공개 API 미제공/개방 제외 → §5.
- **주의**: **성과 시차**(최근 선정 기업은 산출 0에 가까움 → "효율 낮음" 오독 금지, 코호트 정규화). 분류코드 연도별 포맷 상이(기존 함정과 동일).
- **출처**: OpenAPI 목록 https://www.ntis.go.kr/rndopen/api/mng/apiMain.do · 수행기관현황 https://www.data.go.kr/data/15138962/openapi.do

### 3.4 국세청 고액·상습체납 명단 / 3.5 금융위 기업기본정보
- **체납**: 2억↑·1년경과 체납 상호·주소·금액 → 부실 신호. 무료 파일. https://www.data.go.kr/data/15070669/fileData.do (지방세 wetax 별도)
- **계열사**: 기업개요·계열회사·종속기업·지배구조 → 동일 지배구조 **중복지원** 단서(CLAUDE.md 계열사 로드맵). 무료 API. https://www.data.go.kr/data/15043184/openapi.do

## 4. Tier 3 — 보조 (화이트리스트로 관리, 규모 작음)

- **NET/NEP·성능인증(EPC)·조달우수·GS인증**: 기술이 **제품·상용화까지 실증**됨(산출 신호). 공개 명단 검색. NEP/NET https://www.nepmark.or.kr/sub4/sub1.asp · 조달우수 https://pps.go.kr
- **소부장 으뜸기업·뿌리기업**: 정부가 기술력·전략성 **직접 공인**(소수·강력). 보도자료/기관 검색 → 화이트리스트. https://www.sobujang.net
- **IR52 장영실상 등 기술수상**: 경쟁 통과 탁월성(희소·변별력). 연도별 명단. https://www.ir52.com/award/outline.asp
- **기업부설연구소 상세(KOITA rnd.or.kr)**: 전담요원 수·설립일·연구분야 → **형식 vs 실질 연구소** 구분. 개별조회. https://www.rnd.or.kr/user/infoservice/search5.do
- ❌ **국가핵심기술/국가전략기술 "보유"**: 규제·비공개 / 기술 지정이라 **기업 우수성 신호로 오용 금지**.

## 5. 로드맵 / 제외 (무료 아님·자동수집 불가)

| 항목 | 이유 |
|---|---|
| NICE BizAPI / KED | 신용등급·부도·소송 최광범위, 그러나 **유료** |
| KIPA SMART5 특허등급(AAA~C) | 국가기관 특허 質 등급, **로그인·유료** |

| NTIS 기술이전·기술료·사업화 | 사업화 증거 핵심이나 **공개 API 없음** |

| 정부R&D 참여제한 명단 | 외부 조회 불가 → 기업 제출(NTIS 제재확인서) |

## 6. ETL / 연동 설계 방향

- **연동 2종**: 실시간 조회 = API(사업자상태·국민연금·조달·금융위·NTIS·KIPRIS) / 정적 대조 = 파일 정기적재(부정당제재·체납·벤처명단·인증명단).
- **config 기반 매핑**: 소스별 `{엔드포인트, 인증키, 응답필드→내부컬럼 매핑, 갱신주기}` 를 config로 분리(하드코딩 금지). 실제 응답 스키마는 활용신청 후 확정.
- **조인 키 = 사업자등록번호**: 표기차이(하이픈/공백/앞자리 0) 정규화. 사업장명 기반(국민연금 등)은 동명 오매칭 방어(사업자번호 병행 확인).
- **유효기간·취소 필터**: 모든 인증·명단은 만료/취소분 제외(잔존 데이터 주의).
- **시간·분야 보정**: 특허 피인용·NTIS 성과는 연식/분야 코호트 백분위로 상대화(기존 "업종 백분위" 로직 재사용).
- **KIPRIS 호출 한도**: 무료 월 1,000회/서비스 → BULK 다운로드 적재로 대량 처리.

## 7. 신호 → UI 반영(안)

- **결격/리스크 배지**(개요·기술 상단): 폐업 · 부정당제재 · 고액체납 → 적색 경고 + hover 사유.
- **기술력 보강**(R&D 탭): 벤처확인 유형, IPC 집중도, 정부지원 대비 성과(억원당 특허·논문), 특허 심판(IP 리스크), 기술 실증 인증(NET/NEP·조달우수), 정부 공인(소부장 으뜸·IR52).
- **고용 실체**(개요): 국민연금 가입자수 vs 서류상 인원.
- **중복지원 단서**(중복수혜 탭): 금융위 계열사 → 동일 지배구조 교차.
- **데이터 출처·시점 표기**: 각 외부 신호에 출처·기준일 citation, 목업/미연동은 명시(CLAUDE.md 문서화·투명성 원칙).

## 8. 발표 활용 포인트

- 현행 심사는 **자기신고(중복지원 금지 확약서) + 분절 조회**에 의존 → 외부 공공데이터 대조로 **시스템적 교차검증**.
- 무료 공공데이터만으로 **실재·결격·실체·기술형·성과** 검증이 상당 부분 가능 → "정보 비대칭" 문제축에 직접 대응.
- 유료·비공개(신용등급·제재이력·사업화 성과)는 한계로 정직하게 구분 표기 → 데이터 이해도 어필.
