## 5. Ensemble 옵션 (로드맵)

DeepSeek + gpt-4o 병렬 판정 → 두 모델 이견 시 human review flag.

**비용**: 5000기업 20% 시나리오 → DeepSeek $0.52 + gpt-4o $12.3 = **$12.82** (여전히 크레딧 이내)
**효과**: 상용 LLM 파이프라인 수준의 신뢰도. 담당자 화면에 "AI 이견" 배지 표시 → 발표 어필 강력
**우선순위**: Phase 5b 통합 후, 파일럿 gold label 20~30건 확장 시점에 실효성 판단

## 7. 로깅·재산정 계획

Phase 5b 통합 후 첫 batch 100건 호출 시 다음을 로깅:
- 실 `input_tokens` / `output_tokens` / `cache_read_input_tokens`
- 앱 dedup 캐시 히트율

결과로 본 시뮬 재산정 → 팀 공유. 특히 DeepSeek 자동 prompt cache 히트율이 파일럿(50% at 3,4번째)보다 높으면 비용 더 낮아짐.
