# 특허 데이터, 쉽게 이해하기 (팀 공유용)

> 작성: 팀원 B(유환) · 기술력 축 담당
> 대상: 특허를 잘 모르는 팀원 누구나. **특허 지식 없어도 읽을 수 있게** 썼습니다.
> 왜 필요한가: 특허 데이터는 **그냥 세면 틀립니다.** 어디가 함정인지 알아야 다른 축에서 쓸 때도 안 헷갈립니다.

---

## 1. 먼저, 특허 기본 상식 5개

### ① 출원 ≠ 등록 (제일 중요)

| 용어 | 쉬운 말 | 비유 |
|---|---|---|
| **출원** | 특허를 **신청**했다 | 대학에 **원서 접수** |
| **등록** | 심사를 **통과해서 권리를 받았다** | **합격** |
| **공개** | 심사 중인 상태가 공개된 것 | **심사 대기 중** |

**신청했다고 다 받는 게 아닙니다.** 우리 데이터에서 등록 260건 / 공개 128건 → **3건 중 1건은 아직 권리가 없습니다.**

그래서 "특허 있다"는 말은 애매합니다. **"신청했다"인지 "권리를 받았다"인지** 구분해야 합니다.

### ② 지적재산권은 4종류인데, 기술은 그중 2개뿐

| 종류 | 뭘 보호하나 | 기술 실적인가? |
|---|---|---|
| **특허권** | 발명 (기술) | ✅ 예 |
| **실용신안권** | 작은 발명 (기술) | ✅ 예 |
| 상표권 | **브랜드 이름·로고** | ❌ 아니오 |
| 디자인권 | **제품 겉모양** | ❌ 아니오 |

우리 데이터 388건 = 특허권 281 + 상표권 71 + 디자인권 34 + 실용신안 2.

> **상표권은 R&D 성과가 아닙니다.** 회사 로고 등록한 걸 기술 실적으로 세면 안 되겠죠.

### ③ 특허는 매년 유지비(연차료)를 낸다

등록만 하면 끝이 아니라 **자동차세처럼 매년 돈을 내야 유지**됩니다. 안 내면 **권리가 사라집니다(소멸)**.

→ 그래서 **"특허를 포기했다"는 게 신호**가 됩니다. 돈이 없거나, 그 기술을 접었다는 뜻이니까요.

### ④ 신청부터 등록까지 평균 1.5년 걸린다

우리 데이터 평균 **1.53년**. 그래서 최근에 신청한 건 아직 "공개" 상태인 게 정상입니다.

### ⑤ 특허는 회사가 아니라 개인 명의일 수도 있다

우리 데이터에 **대표이사·임원 개인 명의 특허 18건**이 있습니다. 이건 회사 자산이 아니라서, 그 사람이 떠나면 같이 나갑니다.

## 2. ⚠️ 우리 데이터의 함정 4개 — "그냥 세면 틀린다"

### 함정 1. 원본에 있는 "특허 건수" 컬럼이 가짜입니다

KODATA 기업정보 시트에 `특허등록건수(최종건수 누적)`라는 컬럼이 이미 있습니다. 편해 보이죠. **그런데 쓰면 안 됩니다.**

어떤 기업의 연도별 값:
```
2020: 0 → 2021: 2 → 2022: 1 → 2023: 2 → 2024: 0
```

**"누적"인데 2에서 1로 줄었습니다.** 누적이면 계속 늘거나 같아야 하는데 감소해요. → 이 컬럼은 누적이 아니거나 오염된 데이터입니다.

> ✅ **우리 처리**: 이 컬럼 **폐기**. 대신 특허 **원장(388줄)** 을 직접 셉니다.

### 함정 2. 상표·디자인이 섞여 있습니다

`지적재산권 종류` 필터를 안 걸고 세면 로고 등록까지 기술 실적이 됩니다.

| 기업 | 그냥 세면 | 기술 특허만 | 차이 |
|---|---|---|---|
| 695번 | 54건 | **27건** | **-27건 (절반이 상표·디자인!)** |
| 1049번 | 53건 | **26건** | -27건 |
| 1878번 | 5건 | **2건** | -3건 |

695번은 **특허 54개 보유 기술기업**처럼 보이지만, 실제 기술 특허는 27개입니다.

> ✅ **우리 처리**: `특허권 + 실용신안권`만 집계. 상표·디자인 제외.

### 함정 3. NTIS(국가 R&D 과제)가 3배 부풀려집니다

NTIS 데이터는 **매달 스냅샷을 찍어서 저장**하는 구조라, **같은 과제가 여러 줄로 반복**됩니다.

```
원본 170줄  →  실제 과제 59건  (2.9배 뻥튀기)
정부연구비  422억(원본)  →  161억(중복 제거)
```

그냥 세면 **"국가 과제 42건 수주한 회사"** 가 되지만 실제로는 14건입니다.

> ✅ **우리 처리**: `(기업, 총연구기간, 사업명)`이 같으면 한 과제로 묶어서 셉니다.

### 함정 4. 누적 건수는 "과거"입니다

특허 22건 보유 = 우수해 보입니다. 그런데 **그게 언제 낸 건지**는 안 나옵니다.

**117번 기업**: 특허 22건 누적 → 처음엔 R&D 점수 **1위(72.0)** 였습니다.
그런데 확인해보니 **최근 3년간 신규 출원 0건, 마지막 출원이 3.6년 전**입니다. R&D가 멈춘 상태예요.

> ✅ **우리 처리**: "최근 3년 출원 건수", "마지막 출원 이후 공백" 지표 추가 → 점수 **56.6(4위)로 교정**됨.

## 3. 그래서 우리가 만든 지표 (쉬운 말로)

### 🔬 얼마나 연구하나

| 지표 | 쉬운 말 |
|---|---|
| `R&D집약도` | **매출 100원 중 몇 원을 연구에 쓰나** |
| `특허출원_건수` | 특허를 몇 번 **신청**했나 (기술만) |
| `특허등록_건수` | 그중 몇 개가 **권리를 받았나** |

### ⭐ 특허의 "질"

| 지표 | 쉬운 말 |
|---|---|
| `특허등록전환율` | **신청한 것 중 몇 %가 통과했나**. 높으면 알찬 특허, 낮으면 일단 많이 내고 보는 스타일 |
| `첫특허_업력` | 창업하고 **몇 년 만에** 첫 특허를 냈나 (빠르면 기술 지향) |

### ⚡ 지금도 하고 있나 (활동성)

| 지표 | 쉬운 말 |
|---|---|
| `특허_최근출원건수` | **최근 3년간** 몇 건 신청했나 |
| `특허_최근출원비중` | 전체 중 최근 것이 몇 %인가. **낮으면 과거 실적으로 먹고 사는 중** |
| `특허_활동공백년수` | **마지막 신청 이후 몇 년** 지났나. 길수록 정체 |

### 💸 재무 위험 신호

| 지표 | 쉬운 말 |
|---|---|
| `특허소멸률` | **받아놓은 특허 중 몇 %를 포기했나.** 유지비를 못 내고 있다 = 자금 압박 신호 |

실제로 695번 **13.3%**, 2379번 **9.7%** 가 권리를 놓고 있습니다. (나머지는 대부분 0%)

### 🏷️ 어느 분야 기술인가 (신규)

NTIS에 **`과학기술표준분류명`** 이라는 정부 공식 기술 분류가 들어 있습니다. 이걸로 기업의 기술 분야를 판정합니다.

| 기업 | 기술 분야 | 부산TP 4대 중점사업 |
|---|---|---|
| 695 | 바이오센서·생체재료 | **바이오 라이프** |
| 1049 | 소프트웨어·가상현실 | **디지털전환** |
| 616 | 수소·에너지소재 | **탄소중립** |

`기술집중도`로 **한 분야 전문**인지 **여러 분야 다각화**인지도 구분합니다.

### 🚩 서류 vs 실제 (제일 중요한 지표)

| 지표 | 쉬운 말 |
|---|---|
| `인증실체괴리_플래그` | **"인증은 있는데 실적이 없다"** — 이노비즈·벤처 인증 보유 + 등록특허 0 + 국가R&D 0 |

**이게 우리 도구의 존재 이유**입니다. 발제사가 말한 *"서류상 내용과 실제 역량의 차이"* 를 정확히 잡아내니까요.

## 4. 실제 사례 — 이렇게 걸러집니다

### 사례 A. 1878번 — "서류는 우수, 실체는 없음"

- **서류상**: 벤처·메인비즈 인증 보유, 기업부설연구소 있음 → R&D 우수기업처럼 보임
- **실제**: 등록 특허 **1건**, 국가R&D **0건**, R&D비 최하위
- **게다가**: IP 5건 중 **3건이 디자인권**(제품 겉모양) → 기술기업이 아님
- **결과**: R&D특허 점수 **39.4 (최하위)**

### 사례 B. 117번 — "과거의 영광"

- **누적으로 보면**: 특허 22건 → 점수 **72.0 (1위)**
- **활동성을 보면**: 최근 3년 출원 **0건**, 공백 **3.6년**
- **결과**: 교정 후 **56.6 (4위)**

### 사례 C. 1730번 — "지금이 전성기"

- 특허 58건 중 **최근 3년에만 14건**, 공백 1.04년 → 현재 활발

## 5. 다른 축 담당자가 주의할 점

1. **`master_table`의 특허 컬럼 쓰지 마세요.** 가짜입니다(함정 1). `aggregate_tech.py` 결과를 쓰세요.
2. **NTIS 건수를 직접 세지 마세요.** 중복 제거가 필요합니다(함정 3).
3. **NTIS 연구비 단위는 `원`입니다.** 재무 지표는 `천원`이라 섞으면 1000배 틀립니다.
4. **특허의 "기술 분야"는 NTIS에서만 나옵니다.** 특허 원장에는 기술 분류(IPC)도 특허번호도 없어서, 외부 특허DB와 **원장 조인**이 불가능합니다. (단, 실 운영에서 사업자번호가 있으면 KIPRIS에서 **출원인 기준**으로 별도 조회는 가능 — 상세는 `docs/외부데이터_설계노트.md`.)
5. **NTIS 이력이 없는 기업은 기술 분야를 업종으로 추정**합니다. `도메인_출처` 컬럼에 `KSIC추정`으로 표기되니, 화면에 쓸 때 구분해 주세요.

## 6. 한 줄 요약

> 특허 데이터는 **①상표·디자인이 섞여 있고 ②원본 집계 컬럼이 가짜이고 ③NTIS가 3배 중복되고 ④누적 건수는 과거 실적**이라, 그냥 세면 틀립니다.
> 우리는 이 4개를 다 막고, **"진짜 기술이 있나 / 지금도 하나 / 어느 분야인가 / 버티고 있나"** 를 볼 수 있게 만들었습니다.

궁금한 점은 저(유환)에게 물어보세요. 상세 설계 근거는 `docs/기술축_설계노트.md`에 있습니다.
