## 1. 특허 유효/무효 판정 기준

### 실측 — 등록상태 × 등록유효여부 크로스탭 (총 86,820건)

| 등록상태 | 유효=Y | 유효=N | 결측 |
| --- | ---: | ---: | ---: |
| 등록 | **38,756** | **21,546** | 0 |
| 공개 | 0 | 25,467 | 0 |
| 출원 | 0 | 385 | 0 |
| 결측 | 0 | 0 | 666 |

- `공개`(출원 계류)·`출원`은 등록이 아니므로 유효=N인 게 정상 → **권리 미발생**.
- `등록`인데 유효=N인 **21,546건**이 실제 신호(권리소멸·포기·무효·연차료 미납).

### ⚠️ 데이터 이슈 — 출원경과 기반 만료 판정은 버그 (사용 금지)

EDA [2] 출원경과년수가 **특허·실용·상표·디자인 전부 median 56.6년**으로 동일하게 나온다(≈1969년). **출원일 파싱 오류**(Excel 날짜 직렬/포맷 추정)로, `존속기간 만료(경과>20년)` 판정이 **전건 만료로 오판**된다.
→ **존속기간을 출원경과로 재계산하지 않는다.** 원본 `등록유효여부`(Y/N)를 신뢰한다. (출원일 파싱 수정은 EDA/ETL 담당에게 별도 이슈로 전달)

### 판정 기준 (확정)

| 구분 | 규칙 | 실측 건수 |
| --- | --- | ---: |
| **유효 특허** | `등록상태='등록' AND 등록유효여부='Y'` | 38,756 |
| **소멸/무효** | `등록상태='등록' AND 등록유효여부='N'` | 21,546 |
| **권리 미발생** | `등록상태∈{공개,출원}` → 유효 집계 제외(출원건수엔 포함) | 25,852 |
| **미상** | 유효여부 결측 | 666 |

- **특허소멸률 = (등록 & 유효=N) ÷ 등록 = 21,546 / 60,302 = 35.7%** (전체). 기업별로 계산해 **재무 스트레스/조기경보 신호**로 사용.
- 기술축 설계노트 §8의 `is_valid` 기반 소멸률 정의와 일치(= `등록유효여부`).

## 2. NTIS 지역명 표기 편차

`지역구분명` 컬럼 — 30,299 과제행, **고유 126종**. (결측 3,314행 = 10.9%)

### 표기 편차 유형

| 유형 | 사례 | 처리 |
| --- | --- | --- |
| **입도(정밀도) 불일치** | `부산광역시 금정구`(3,999) vs `부산광역시`(398) vs `부산광역시 기타`(2) — 같은 시도인데 시군구/시도/기타 혼재 | 시도 레벨 롤업 |
| **시도명 중복 표기** | `세종특별자치시 세종특별자치시`(174), `해외 해외`(7) vs `해외`(2) | 앞 토큰만 취함 |
| **행정구역 개편** | `전라북도 전주시`(28) vs `전북특별자치도 전주시`(5) — 2024 전북특별자치도 전환 이중 표기 | 별칭 매핑(기준 통일) |
| **옛 구명/오입력** | `인천광역시 남구`(2018 미추홀구 개칭), `전라남도 북구`(7 — 전남엔 북구 없음, 오입력 의심) | 매핑표 + 예외 로그 |
| **결측·기타** | `(결측)` 3,314, `기타 기타` 1,861 | "미상" 통일 |

### 분포 참고 (EDA)

- NTIS 참여 기업 2,886곳 중 지역 **0종류(결측) 68.3%**, 1종류 22.2%, 2+종류 9.5%.
- 여러 지역 가진 기업(274곳)의 **최빈값 점유율 median 70.7%** → 최빈값 대체 손실 적음. 단 최빈<50%인 **13곳은 애매** → "복수지역" 표기.
- 부산 압도적 집중(금정·강서·남구…)은 부산TP 데이터 특성 → 일반화 금지.

### 정규화 방안 (제안)

1. **시도 레벨 롤업** — 앞 토큰을 표준 17개 시도로 매핑(편차 대부분 해소). 부산 세부 구가 필요하면 부산만 2단 유지.
2. **`config/region_map.yaml`** 로 별칭·개편 매핑 (전북특별자치도→전라북도, 강원특별자치도→강원도, `세종…세종`→세종, `해외 해외`→해외). 부처명 정규화(`ministry_map.yaml`)와 동일 패턴.
3. **결측/기타 → "미상"** 통일 (임의 추정 금지 — 도메인_출처 원칙과 동일).
4. **기업당 여러 지역 → 최빈값 대체**, 최빈<50%는 "복수지역".
